## 常用命令

| 命令 | 作用 |
|---|---|
| `git status` | 看当前有哪些改动 |
| `git add .` | 把改动加入暂存区 |
| `git commit -m 说明` | 提交到本地历史 |
| `git push` | 推送到 GitHub |
| `git pull` | 把 GitHub 上的更新拉下来 |

> 学 Git 最好的方式就是每天用这三条：`git status` -> `git add` -> `git commit`。
